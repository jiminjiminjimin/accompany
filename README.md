# 안심 동행

노인 주간보호센터의 장소·어르신 관리 및 GPS 도착 추정 기록 Android 앱입니다.

- 장소/어르신 등록·수정·삭제, 별도 ID와 여러 장소 연결, 장소 일괄 등록
- 주소 검색 결과 선택, 현재 GPS 위치 등록, 좌표 직접 입력
- 등원/하원 운행, 대상·장소 선택, 시작/종료, 운행 내역 조회
- 운행 중 등록 장소 반경 50m에서 연속 20초 정차 시 어르신별 도착 추정 자동 기록
- 위치 오차 30m 이하, 수신 간격 최대 5초, 이동 속도/좌표 변화 확인, 운행별 중복 기록 방지
- Android Keystore + AES-256-GCM 저장, 기존 v1/v2 데이터 읽기 호환성
- 기기 인증 앱 잠금, 백업/기기 이전 제외, 화면 캡처 차단

운행 감지 서비스가 실행 중이면 화면 꺼짐·앱 잠금·홈 이동 중에도 GPS 도착을 기록합니다. 강제 종료 또는 OS에 의한 서비스 중단 후에는 앱에서 감지 재개를 눌러야 합니다. 운행 상태와 감지 상태를 구분해 안내합니다. 전체 이동 경로는 저장하지 않으며, GPS 기록은 실제 승하차 확인이 아닌 위치 기반 추정입니다.

운행 알림, 감지 중단·재개 안내, 종료 전 미기록 대상 확인을 제공합니다. 장소 판정 반경 50m와 현재 GPS 오차를 구분해 표시합니다. 기록 수동 수정·이력, 엑셀 출력은 후속 범위입니다.

## 실행과 검증

Android Studio에서 이 프로젝트를 열고 기존 Gradle/JDK/SDK 버전을 유지합니다. 기기에 PIN·패턴·비밀번호를 설정하고, 앱의 정확한 위치 권한과 기기 GPS를 허용해 주세요.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-debug.ps1 -Offline -NoDaemon -NoConfigurationCache
```

APK: `app\build\outputs\apk\debug\app-debug.apk`

로컬 Gradle 의존성/Wrapper 캐시는 PC별로 다릅니다. 스크립트용 캐시에 배포본이 없으면 Android Studio에서 빌드하거나 정상 네트워크에서 캐시를 준비합니다. 버전을 임의로 바꾸지 않습니다.
