# 안심 동행

주간보호센터의 어르신·승하차장소를 관리하고, GPS를 이용해 등·하원 도착 시간을 추정하여 기록하는 Android 앱입니다.

## 개발 현황 · 2026-10-19

**주요 기능 구현 완료 / 실기기 인수 검증 및 운영 배포 보안 점검 진행 중**

| 영역 | 현재 상태 |
| --- | --- |
| 어르신·장소 등록/수정/삭제 및 연결, 장소 일괄 등록 | 구현 |
| 가나다순 자동 정렬, 주소 검색·GPS·좌표 입력 | 구현 |
| 등원/하원 별도 시작, 대상·장소 선택, 종료 | 구현 |
| GPS 정차 기반 도착 추정 및 백그라운드 감지 | 구현·기기별 지속 동작 추가 검증 필요 |
| 날짜별 운행 내역 및 상세 조회 | 구현 |
| 이동 경로 지도·시간 슬라이더 | 구현·Android WebView 실제 지도 검증 필요 |
| 날짜 선택 XLSX 내보내기 | 구현 |
| 블루 테마, 심볼, 하단 플로팅 탭 | 반영 |
| 화면 회전 시 앱 접근 상태 유지 | 반영·기기 테스트 미실행 |
| 기기 잠금 해제 상태 또는 잠금 미설정 시 자동 진입 | 반영 |
| 로컬 저장 암호화 | Android Keystore + AES-256-GCM 구현 |
| 코드 기반 보안 보고서 | 작성 완료·운영 보안 개선/실기기 검증 남음 |

엑셀에는 날짜, 어르신 이름, 등원 시간, 하원 시간이 표시됩니다. **내보낸 XLSX는 암호화되지 않습니다.** 앱 내부 암호화 저장과 별개입니다.

GPS 기록은 실제 승하차 확인이 아닌 위치 기반 추정입니다. 등록 장소 반경 50m에서 연속 20초 정차하고 위치 오차가 30m 이하인 경우를 기준으로 하며, 수신 간격·속도·좌표 변화도 확인합니다. 운행 중 정확도 30m 이하의 위치를 약 5초 간격으로 선별하여 암호화 저장합니다. 운행 내역의 상세 화면에서 이동 기록 지도를 열 수 있습니다. 도착 기록이 모두 끝나도 이동 경로는 운행 종료를 누를 때까지 기록합니다.

운행 감지 서비스가 실행 중이면 화면 꺼짐·홈 이동 중에도 기록하도록 구현했습니다. 강제 종료 또는 OS에 의한 서비스 중단 후에는 앱에서 감지를 재개해야 합니다. 기기별 절전 정책에서의 실제 동작은 별도 검증이 필요합니다.

운행 내역 → 운행 선택 → **이동 기록 지도 보기**에서 저장된 경로, 첫·마지막 기록 위치, 대상 장소와 시각별 위치를 확인합니다. 기능 추가 전 운행의 이동 경로는 복원되지 않습니다. 배경 지도는 인터넷이 필요하며 OpenStreetMap 서버에 표시 영역의 타일을 요청합니다. 이동 좌표 목록과 대상 이름을 지도 서버에 업로드하지 않습니다.

## 보안 범위

앱 내부 데이터는 Android Keystore의 AES 키로 암호화해 내부 저장소에 보관합니다. 백업 제외와 화면 캡처 제한을 설정했습니다. 키에 사용자 인증을 강제하는 설정은 없습니다. 기기가 잠금 해제된 상태이거나 화면 잠금이 설정되지 않았다면 앱에 자동 진입하므로, 별도의 사용자 인증 경계로 보아서는 안 됩니다. [코드 기반 보안 분석 보고서](docs/SECURITY-REVIEW-2026-10-19.md)에 확인된 통제와 한계, 미검증 항목을 정리했습니다.

## 빌드와 검증

Android Studio에서 프로젝트를 열고 기존 Gradle/JDK/SDK 설정을 사용합니다. 정확한 위치 권한과 GPS가 필요합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-debug.ps1 -Offline -NoDaemon -NoConfigurationCache
```

산출물: `app/build/outputs/apk/debug/app-debug.apk`. 개발용 디버그 APK이며 운영 배포본이 아닙니다.

이동 경로 기능을 포함한 로컬 JUnit 검증 결과는 [이동 기록 지도 개발 내역](docs/ROUTE-MAP-2026-10-19.md)을 확인해 주세요. Android 기기 테스트는 기존 설치본과 서명이 달라 실행하지 못했습니다. 기존 자료를 보호하기 위해 앱을 삭제하지 않았습니다.
