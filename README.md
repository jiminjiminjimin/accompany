# 안심 동행

주간보호센터의 어르신·승하차장소를 관리하고, GPS를 이용해 등·하원 도착 시간을 추정하여 기록하는 Android 앱입니다.

## 개발 현황 · 2026-10-19

**주요 기능 구현 완료 / 실기기 인수 검증 및 운영 배포 보안 점검 진행 중**

| 영역 | 현재 상태 |
| --- | --- |
| 어르신·장소 등록/수정/삭제 및 연결, 장소 일괄 등록 | 구현 |
| 가나다순 자동 정렬, 임시 주소 검색·GPS·지도 핀 선택 | 구현 |
| 등원/하원 별도 시작, 대상·장소 선택, 종료 | 구현 |
| GPS 정차 기반 도착 추정 및 백그라운드 감지 | 구현·기기별 지속 동작 추가 검증 필요 |

엑셀에는 날짜, 어르신 이름, 등원 시간, 하원 시간이 표시됩니다. **내보낸 XLSX는 암호화되지 않습니다.** 앱 내부 암호화 저장과 별개입니다.

GPS 기록은 실제 승하차 확인이 아닌 위치 기반 추정입니다. 등록 장소 반경 50m에서 연속 20초 정차하고 위치 오차가 30m 이하인 경우를 기준으로 하며, 수신 간격·속도·좌표 변화도 확인합니다. GPS 샘플은 도착 판단에만 사용하며 이동 경로는 저장하지 않습니다. 모든 대상의 도착 기록이 저장되면 GPS 감지를 중지하고, 운행 종료 버튼으로 종료 시각을 저장합니다.

운행 감지 서비스가 실행 중이면 화면 꺼짐·홈 이동 중에도 기록하도록 구현했습니다. 강제 종료 또는 OS에 의한 서비스 중단 후에는 앱에서 감지를 재개해야 합니다. 기기별 절전 정책에서의 실제 동작은 별도 검증이 필요합니다.

승하차 장소 선택 지도는 유지합니다. 배경 지도는 인터넷이 필요하며 OpenStreetMap 서버에 표시 영역의 타일을 요청합니다.

## 보안 범위

2026-10-21: 최신 소스 7589268의 MobSF 정적 분석 및 제한된 동적 검사를 수행했습니다. 지도 타일 캐시 잔존을 확인했으며 API 감시와 TLS 검증은 미완료입니다. [보안 검사 현황·한계·후속 점검](docs/SECURITY-TEST-2026-10-21.md)을 참고하세요. 이전 빌드의 36점과 이번 분석본의 56점은 동일 조건 비교가 아닙니다.

앱 내부 데이터는 Android Keystore의 AES 키로 암호화해 내부 저장소에 보관합니다. 백업 제외와 화면 캡처 제한을 설정했습니다. 키에 사용자 인증을 강제하는 설정은 없습니다. 기기가 잠금 해제된 상태이거나 화면 잠금이 설정되지 않았다면 앱에 자동 진입하므로, 별도의 사용자 인증 경계로 보아서는 안 됩니다. [코드 기반 보안 분석 보고서](docs/SECURITY-REVIEW-2026-10-19.md)에 확인된 통제와 한계, 미검증 항목을 정리했습니다.

## 빌드와 검증

Android Studio에서 프로젝트를 열고 기존 Gradle/JDK/SDK 설정을 사용합니다. 정확한 위치 권한과 GPS가 필요합니다.

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build-debug.ps1 -Offline -NoDaemon -NoConfigurationCache
```

산출물: `app/build/outputs/apk/debug/app-debug.apk`. 개발용 디버그 APK이며 운영 배포본이 아닙니다.

이동 경로 수집·저장·조회 기능은 제거했습니다. 과거 개발 문서의 해당 기능 설명은 당시 이력입니다.

## 좌표 중심 장소 저장 (v6)

주소 검색어와 검색 결과 주소는 등록 화면에서 지도 초기 위치를 찾는 임시 데이터입니다. 저장 시 장소 이름, 최종 위도·경도와 어르신 연결을 보관하고, 주소 문자열은 장소 및 운행 대상 스냅샷 JSON에 기록하지 않습니다. 저장 완료 후 등록 화면을 닫아 임시 검색 상태를 해제합니다. 수정 화면은 기존 좌표에서 시작하며 주소는 빈 검색창으로 표시됩니다.

기존 v1~v5 암호화 자료는 앱이 자료를 열 때 v6로 원자적으로 다시 저장하여 장소 및 과거 운행 대상의 주소 필드와 이동 경로 데이터를 제거합니다. 좌표가 없는 구형 장소는 추정 좌표를 만들지 않고 재지정 안내를 표시합니다. v6 저장 이후 구버전으로 되돌리면 자료를 읽을 수 없습니다. 기기에 이미 내보낸 파일이나 외부 검색 서비스에 전달된 검색어, 저장장치의 삭제 흔적에 대한 물리적 완전 삭제를 보장하지 않습니다.

좌표 역시 정확한 위치 정보입니다. 주소 검색 서비스 및 온라인 지도 타일 통신은 유지되므로 완전한 오프라인 앱은 아닙니다. 새 기기에 처음 설치하는 APK에는 테스트 중 기기에 입력한 자료가 포함되지 않습니다.
