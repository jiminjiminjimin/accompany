## 실제 코드 변경

- 엑셀 쓰기 도중 CancellationException이 발생하면 생성 문서 정리를 시도하고 동일한 취소 예외를 다시 던진다. 일반 TripExportFailure로 감싸 취소 의미를 잃지 않도록 했다.
- MainActivity의 내보내기 내부 경계에서도 취소 예외를 구분해 외부 취소 처리까지 전달한다.
- 파일 선택기 오류 시 기존처럼 세션과 busy 상태를 복구하고 안내한다. 예상 밖 오류의 로그에는 예외 메시지·URI·이름·좌표를 넣지 않는다.
- 기존 파일 저장 실패의 정리, 스트림 닫기, 원인 전달과 사용자 안내를 유지한다. broad catch를 완전히 없애면 공급자별 예외에서 정리가 생략되거나 앱이 종료될 수 있어 무리하게 제거하지 않았다.
- 데이터 형식, 암호화 키/해시, 지도/주소 검색, GPS, exported 설정은 변경하지 않았다.

## 남은 한계와 다음 확인

- Sparrow 재분석 전에는 경고 감소/해소 건수를 주장할 수 없다. 최종 Exception 경계는 의도적으로 남아 경고가 유지될 수 있다.
- 기존 ZIP과 수정본을 동일 규칙으로 비교하고 DNS 경고는 실제 DNS source/sink 근거를 확인해야 한다. 근거 없는 전체 억제는 적용하지 않았다.
- 실제 기기/문서 공급자에서 파일 선택 취소, 쓰기 중 화면 종료, 저장공간 부족, 권한 철회, 내보낸 XLSX 열기를 확인해야 한다. 단위 테스트는 모든 공급자 동작을 보증하지 않는다.
- 이전 MobSF의 지도 캐시/TLS/API 감시 미완료 사항은 이번 수정으로 해결된 것이 아니다.
