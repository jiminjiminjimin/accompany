# 2026-10-19 추가 오류 수정

기준 소스: f1ff288 이후 로컬 변경. 원래 앱/별도 앱의 설치·삭제 및 실제 등록 자료 변경은 수행하지 않았다.

## 수정한 내용

- 엑셀 저장의 중복 실행 방지를 파일 선택창 대기부터 파일 쓰기 종료까지 적용했다. 다른 요청이 원래의 선택 날짜/운행 ID를 덮어쓰지 못한다.
- 파일 선택을 취소하면 다시 저장할 수 있으며, Activity 재생성 시 아직 열려 있는 파일 선택의 운행 ID와 대기 상태를 복원한다.
- 출력 스트림을 두 번 닫는 경로를 차단하고 완료 시 저장 성공 안내를 표시한다.
- 쓰기/닫기/원본 읽기 실패 시 CreateDocument가 반환한 새 출력 문서만 삭제를 시도한다. 제공자가 삭제를 허용하지 않으면 불완전 파일을 확인하라는 안내를 표시한다. 앱 내부 암호화 자료는 이 정리 대상이 아니다.
- 등원/하원 대상 선택창에서 이름 전체를 눌러 선택·해제할 수 있다. 여러 연결 장소도 장소명 행 전체로 선택한다. 주소는 노출하지 않고, 단일 연결 장소는 자동 선택하는 기존 동작을 유지한다.

## 회전·잠금 확인

최신 코드의 configChanges, 회전 중 onStop 예외 처리와 수동 잠금 상태 복원을 확인했다. 잠금 정책 자체를 변경하지 않았다. 회전 중 편집 입력 유지에 대한 기존 기기 테스트 외에, 수동 잠금 상태가 가로/세로 회전으로 풀리지 않고 명시적 진입 버튼으로만 닫히는 테스트를 추가했다.

## 검증 범위

- 로컬 JUnit 47개 통과, 실패 0(기존 41개 + 엑셀 요청/출력 흐름 6개).
- 디버그 앱 빌드 및 기기 테스트 APK 컴파일 성공.
- 추가 UI 테스트: 어르신 이름 터치로 선택, 주소와 단일 장소 숨김, 여러 장소 중 다른 장소명 선택, 수동 잠금 후 회전.
- 기기 테스트는 컴파일만 확인했다. 화면 회전·파일 제공자별 실패 처리는 실제 기기에서 추가 확인해야 한다. 새 테스트용 앱은 설치하지 않았다.
