# 운행내역 삭제 기능

- 운행 내역 → 종료된 운행 상세에서 `어르신 이름 기록 삭제` 또는 `운행 전체 삭제`를 선택한다.
- 확인창에 운행 일시, 등·하원, 삭제 대상, 복구 불가 안내를 표시한다. 취소하면 변경하지 않는다.
- 어르신별 삭제는 그 운행의 해당 ID 대상 및 도착 기록만 삭제한다. 동명이인을 이름으로 구분하지 않는다.
- 마지막 대상 삭제 시 빈 운행을 남기지 않고 해당 운행을 삭제한다.
- 진행 중인 운행 삭제는 UI와 데이터 함수에서 차단한다. 등록된 어르신·장소·연결과 다른 운행은 보존한다.
- 기존 SecureCareStore.update 저장 경로를 사용한다. 저장 성공으로 데이터가 갱신된 뒤 확인창이 닫히며, 실패하면 재시도할 수 있다.
- 저장 및 엑셀 내보내기 중에는 삭제 확인 버튼을 비활성화한다. 이미 외부에 내보낸 엑셀 파일은 삭제하지 않는다.
- 단위 테스트: 동명이인 ID 구분, 대상/도착 동시 삭제, 다른 데이터 보존, 직렬화 왕복, 전체/마지막 대상 삭제, 진행 중 삭제 거부, 반복 삭제.
- UI 계측 테스트 추가: 확인 전 데이터 유지, 취소, 확인 후 빈 목록. 기기 실행 여부는 커밋 전달 시 별도 안내한다.

## 검증 결과

- JVM 단위 테스트 62개 통과 (실패 0, 오류 0).
- Debug APK 빌드 성공.
- UI 계측 테스트는 컴파일 검증만 수행하며 실제 기기에서는 실행하지 않았다. 사용자 앱 설치·삭제 및 데이터 변경은 하지 않았다.
