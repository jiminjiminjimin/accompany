# 안심 동행 사용법·유의사항

2026-10-24 · 1.0.2-test · Android 14 이상. 설치는 `INSTALL-ANDROID14.md`를 먼저 읽으세요.

## 1. 처음 시작하기

기관이 자체 제작 앱 설치를 허용하는 업무용 휴대폰에서 사용합니다. 휴대폰에 화면 잠금을 설정하고 OS와 Android System WebView를 최신 상태로 유지합니다. 이 앱은 별도 계정·사용자별 권한 시스템이 아니며, 휴대폰 잠금이 풀려 있으면 앱에 자동 진입할 수 있습니다.

처음에는 가상 어르신 이름과 공개 장소로 아래 과정을 확인하세요. 새 기기의 APK에는 기존 테스트 명단·좌표·운행 자료가 들어 있지 않습니다. 기존 설치를 업데이트하면 그 기기의 저장 자료는 유지될 수 있습니다.

## 2. 어르신과 승하차장소 등록

1. **어르신명단 → 어르신 추가**에서 이름을 등록합니다.
2. **승하차장소 → 장소 추가 · 여러 장소 등록**으로 들어갑니다.
3. 알아보기 쉬운 장소 이름을 정합니다. 이름 칸에 상세 주소나 불필요한 개인정보를 넣지 않습니다.
4. 주소 검색창에 장소 주소를 넣고 **주소 검색**에서 결과를 선택합니다. 검색어는 외부 검색 서비스로 전달될 수 있습니다.
5. 지도가 해당 위치로 이동하면 핀을 끌거나 지도를 눌러 실제 승하차 지점으로 조정합니다. 실제 거주지의 정확한 위치보다 주변의 안전한 승하차 지점을 선택하는 것을 권장합니다.
6. 연결할 어르신을 선택하고 저장합니다. 여러 장소가 필요하면 **다른 주소 추가**를 사용합니다.

저장되는 자료는 장소 이름·좌표·연결입니다. 검색 주소 필드는 저장하지 않지만, 외부 검색 서비스에 전달된 검색어까지 삭제되는 것은 아닙니다. 지도/검색에는 인터넷이 필요하며, GPS 현재 위치에는 위치 권한이 필요합니다. 지도가 안 뜨면 통신 상태를 확인하고 지도 다시 불러오기를 이용합니다.

## 3. 등원·하원 운행

1. **운행시작 및 기록 → GPS 운행 기록**에서 등원 또는 하원 운행 시작을 선택합니다.
2. 대상 어르신을 선택합니다. 전체선택/선택 해제를 사용할 수 있고, 연결 장소가 여러 곳이면 이번 운행의 장소를 선택합니다.
3. 대상·장소를 확인하고 운행을 시작합니다. GPS 추정을 위해 정확한 위치와 필요한 알림 권한을 허용합니다.
4. 진행 화면에서 도착 상태를 확인합니다. 필요하면 감지를 중단·재개합니다. 시작 시 대상 이름과 장소 좌표의 당시 사본이 운행에 저장됩니다.
5. 끝나면 **운행 종료**로 종료 시각을 기록합니다. 모든 대상의 도착이 기록되면 GPS 감지는 멈추지만 운행 종료 확인은 별개입니다.

반경 50m, 위치 정확도 30m 이하, 연속 20초 정차 등 기준으로 추정합니다. GPS 오차·실내·위치 조작·기기 시각·절전 때문에 실제 도착과 다를 수 있습니다. **실제 탑승/하차는 사람이 확인해야 합니다.** 운전 중 휴대폰을 조작하지 않습니다. 강제 종료·절전으로 감지가 멈출 수 있으므로 첫 운행 전 안전한 환경에서 장시간 테스트합니다.

## 4. 내역 확인과 삭제

**운행 내역 → 종료된 운행**을 선택하면 당시 대상과 도착 추정 시각이 보입니다.

- **○○ 기록 삭제:** 선택한 어르신의 해당 운행 기록만 삭제합니다. 동명이인은 이름이 아닌 내부 ID로 구분합니다.
- **이 운행 전체 삭제:** 지금 상세창에서 선택한 운행만 삭제합니다. 모든 날짜의 전체 운행을 지우는 버튼이 아닙니다.
- 확인창에서 날짜·방향·대상을 확인합니다. 취소하면 변경되지 않습니다. 마지막 대상 기록을 지우면 빈 운행도 삭제됩니다.
- 진행 중인 운행은 삭제할 수 없습니다. 삭제가 저장되면 앱에서 복구하는 기능은 없습니다.

등록된 어르신·장소와 다른 운행은 유지됩니다. 명단에서 어르신을 지우는 것만으로 과거 운행 기록이 삭제되지는 않습니다. 이미 내보낸 엑셀도 따로 관리해야 합니다.

## 5. 엑셀 내보내기

운행 내역에서 필요한 날짜/종료 운행을 선택하고 **엑셀로 저장(.xlsx)**을 사용합니다. 출력 항목은 날짜·이름·등원/하원 시각이며 좌표·주소는 제외됩니다.

**엑셀 파일에는 암호가 없습니다.** 기관이 승인한 저장 위치와 공유 방법을 사용하세요. 클라우드 저장 위치는 외부 전송을 수반할 수 있습니다. 파일 선택 취소나 오류가 나면 안내를 읽고 재시도하며, 불완전한 파일이 남았는지도 확인합니다. 엑셀을 이용해 앱 명단·장소·전체 기록을 복원하는 기능은 없습니다.

## 6. 업무폰에서 꼭 알아둘 점

- 저장 자료는 앱 전용 공간에서 암호화하지만 열린 휴대폰·루팅·악성 접근성·입력기·메모리 공격까지 안전하다고 보장하지 않습니다.
- 지도 서버는 조회 영역·IP 등을 알 수 있고 지도 캐시도 남을 수 있습니다. 모든 동작이 기기 안에서만 처리되는 앱은 아닙니다.
- 자동 백업/기기 이전이 제외되어 앱 삭제·데이터 초기화·분실·키 소실 시 복구하기 어렵습니다. 설치 오류 때문에 기존 앱을 바로 삭제하지 마세요.
- 보안 검사 일부는 이전 APK에 대한 결과입니다. 이번 APK의 MobSF/Sparrow/TLS 전체 재검사와 회사 휴대폰 실차 검증은 완료되지 않았습니다.
- 기관에서 자료 보관 기간·삭제 책임·엑셀 공유 범위·업무폰 잠금 정책을 정한 뒤 실제 개인정보를 사용하세요.

## 7. 간단한 인수 체크리스트

- [ ] 가상 명단·장소 등록 및 핀 선택/편집 확인
- [ ] 앱을 닫고 다시 열었을 때 자료 유지 확인
- [ ] 등원/하원 시작·감지 중단/재개·종료·내역 확인
- [ ] 삭제 확인창 취소 및 테스트 기록의 개별/전체 삭제 확인
- [ ] 실제 엑셀 뷰어에서 가상 출력물 열기 및 안전한 폐기
- [ ] 잠금·홈 이동·절전·권한 거부·오프라인 조건에서 안내와 복구 확인
