## 개인정보와 분석 환경
처음 정적 분석은 인터넷 차단 Docker 네트워크에서 수행. 동적 준비용 별도 로컬 컨테이너는 도구 다운로드 및 테스트 통신을 위해 인터넷 연결이 있음. 두 컨테이너 모두 VirusTotal 기능과 도메인 악성 조회를 비활성화. 동적 준비 컨테이너에서는 MobSF 기본 Play Store 메타데이터 조회 및 tracker DB 업데이트가 발생할 수 있음. 외부 검사 업체에 APK를 업로드한 것은 아님.

기존 emulator-5554와 사용자 자료는 변경하지 않음. Android 11 분석 기기는 /system 및 부팅 문제로 중단. 별도 Accompany_MobSF_API28(Android 9, emulator-5560)에서 MobSF 동적 분석 시작·종료 및 보고서 생성 성공. 분석 후 전용 기기를 종료했으며 앱 소스 작업 트리는 깨끗함.

## 중요한 분석 한계
- Frida 17.23.3 서버와 스크립트 주입 로그는 있으나 최종 apimon={}, frida_logs=false. API 호출 감시 결과를 확보하지 못했으므로 암호화 함수 호출·메모리 내 평문·키 사용에 대한 동적 검증은 미완료.
- tls_tests=null. 인증서 검증, MITM 저항성, 인증서 고정 여부를 통과했다고 주장할 수 없음. 타일 URL 캐시는 통신 흔적이며 성공한 HTTP 응답이나 전체 패킷 캡처를 대체하지 않음.
- 주소 검색/장소 저장까지만 실행. 운행 시작·도착 추정·백그라운드 GPS·어르신 연결·엑셀 내보내기·기기 잠금·핀 드래그·데이터 마이그레이션·최신 Android는 이번 동적 검사 범위 밖.
- 따라서 정적 분석 완료 + 제한된 동적 실행/파일 검사 완료 상태이며 전체 보안 검증 완료가 아님.
