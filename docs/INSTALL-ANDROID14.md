# 안심 동행 테스트 APK 설치 안내

작성일: 2026-10-23

## 파일과 설치 조건

- APK: `accompany-1.0.1-test-android14.apk`
- 버전: 1.0.1-test / versionCode 2
- Android 14(API 34) 이상 필요. Android 13 이하는 설치할 수 없습니다.
- 개인 테스트용 서명으로 서명한 Release 빌드입니다. 공식 운영 배포나 보안 인증을 의미하지 않습니다.
- 앱에는 사용자 명단·장소·운행 기록을 담아 배포하지 않습니다. 기존 설치 위에 업데이트하면 기존 데이터는 남을 수 있습니다.

## 직장 휴대폰에 설치하기

1. 직장 휴대폰에서 자체 제작 앱 설치가 허용되는지 기관 담당자에게 확인합니다. 회사 관리 정책(MDM)이 차단하면 우회하지 않습니다.
2. 휴대폰의 설정 → 휴대전화 정보 → 소프트웨어 정보에서 Android 14 이상인지 확인합니다.
3. USB 파일 전송으로 APK를 휴대폰의 Download 폴더에 복사합니다. USB 디버깅은 필요하지 않습니다.
4. 휴대폰 파일 관리 앱에서 APK를 엽니다. 해당 파일 관리 앱의 '출처를 알 수 없는 앱 설치' 허용이 필요하면, 기관에서 허용하는 경우에만 일시적으로 허용합니다. 제조사에 따라 메뉴 이름이 다릅니다.
5. 설치를 마치면 위 설치 허용을 다시 끕니다. Play Protect를 끄거나 보안 경고를 무시하지 마세요. 차단되면 표시된 내용을 확인하고 담당자에게 문의합니다.
6. 안심 동행을 실행합니다. GPS 운행 테스트 시 정확한 위치와 필요한 알림 권한을 허용합니다. 권한을 거부하면 일부 기능이 제한될 수 있습니다.

### 기존 앱이 설치되어 있다면

패키지 이름은 `com.example.pathreport`입니다. 기존 Android Studio Debug 앱이나 다른 키로 서명된 APK와는 서명이 달라 업데이트 설치가 거부될 수 있습니다. 이 경우 **기존 앱을 즉시 삭제하지 마세요.** 앱 삭제·데이터 삭제는 로컬 암호화 자료를 잃게 할 수 있습니다. 내보낸 엑셀도 전체 복구용 백업은 아닙니다. 데이터 없는 별도 테스트 기기 사용을 우선합니다.

## 첫 테스트 순서

처음에는 실제 어르신 정보 대신 가상 이름과 공공장소 좌표를 사용하세요.

1. 가상 어르신을 등록하고 장소를 연결합니다.
2. 주소 검색 → 지도 초기 위치 확인 → 핀 이동 → 저장을 확인합니다. 검색 주소 자체는 저장 대상에서 제외되지만 장소 이름에 직접 적은 주소는 이름으로 저장됩니다.
3. 앱을 완전히 종료한 뒤 다시 열어 자료가 유지되는지 확인합니다.
4. 안전한 보행 환경에서 운행 시작·도착 추정·종료·운행 내역을 확인합니다. 운전 중 휴대폰을 조작하지 않습니다.
5. 가상 운행 기록을 엑셀로 내보내고 내용을 확인한 뒤 테스트 파일을 삭제합니다. 엑셀은 암호화되지 않습니다.
6. 화면 잠금·앱 잠금·권한 거부·네트워크 끊김에서 동작을 확인합니다. GPS 도착 추정은 실제 승하차 확인을 대신하지 않습니다.

## 보안상 알아둘 점

- 이름·장소 좌표·운행 기록은 앱 전용 공간에서 AES-GCM으로 암호화해 저장하고 Android Keystore로 키를 관리합니다. 일반 앱과 파일을 공유하지 않습니다.
- 주소 검색과 OSM 지도 조회는 외부 통신입니다. 검색 제공자는 검색어를, 지도 서버는 조회 지역과 IP 등을 알 수 있습니다. 완전한 오프라인 앱은 아닙니다.
- 잠금이 풀린 기기, 루팅 기기, 악성코드, 내보낸 엑셀까지 모두 보호한다는 뜻은 아닙니다. 기기 화면 잠금과 운영체제·WebView 업데이트가 필요합니다.
- 어르신이나 장소를 삭제해도 과거 운행 기록의 당시 이름·좌표가 남을 수 있습니다.
- 이 APK가 보안상 문제없다고 보장할 수 없습니다. Android 14 이상 실제 휴대폰 동작 및 TLS 가로채기 공격 시험은 아직 완료되지 않았습니다.
- 테스트 결과와 알려진 한계는 함께 제공하는 `DATA-SECURITY-PLAIN-LANGUAGE-2026-10-23.md`를 확인하세요. 실제 개인정보를 사용한 운영 전에는 기관의 검토가 필요합니다.

## APK 무결성 확인 (PC)

PowerShell에서 다음 명령으로 APK의 SHA-256을 확인하고 `SHA256SUMS.txt`와 비교합니다.

```powershell
Get-FileHash 'E:\DaycareApp\accompany-1.0.1-test-android14.apk' -Algorithm SHA256
```

서명키와 비밀번호는 APK 폴더나 GitHub에 포함하지 않습니다. 동일 서명의 후속 업데이트에는 제작 PC에 보관된 테스트 서명키가 필요합니다.
