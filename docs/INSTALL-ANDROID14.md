# 안심 동행 설치·업데이트 안내

2026-10-24 · **1.0.2-test / versionCode 3** · Android 14 이상.

## 설치할 파일

`accompany-1.0.2-test-android14.apk`를 사용합니다. `previous-1.0.1-test` 폴더의 파일은 과거 버전입니다. 이 APK에는 개인 명단·좌표·운행 기록이 포함되어 있지 않습니다. 기존 앱을 업데이트하면 기기의 기존 자료는 남을 수 있습니다.

## 회사 휴대폰에 처음 설치

1. 설정 → 휴대전화 정보에서 **Android 14 이상**인지 확인합니다.
2. 기관에서 자체 제작 앱 설치를 허용하는지 확인합니다. MDM이나 보안 기능이 막으면 우회하지 말고 담당자에게 문의합니다.
3. PC와 휴대폰을 USB 파일 전송으로 연결하고 APK를 휴대폰 Download 폴더에 복사합니다. USB 디버깅은 필요하지 않습니다.
4. 휴대폰 '내 파일'에서 APK를 엽니다. 기관에서 허용하는 경우 해당 파일 관리 앱의 '출처를 알 수 없는 앱 설치'를 일시 허용할 수 있습니다. 설치 후 다시 끕니다.
5. Play Protect를 끄거나 보안 경고를 무시하지 마세요. 설치가 차단되면 표시된 오류를 확인합니다.
6. 앱을 열고 GPS 운행에 필요한 정확한 위치·알림 권한을 허용합니다. 권한을 거부하면 기능이 제한될 수 있습니다.
7. [사용법·유의사항](USER-GUIDE-2026-10-24.md)에 따라 가상 이름·공공장소로 먼저 확인합니다.

## 기존 앱 업데이트

이전 **1.0.1-test 배포 APK와 동일한 서명키**를 사용하고 versionCode를 2에서 3으로 올렸습니다. 그 앱에는 새 APK를 열어 업데이트할 수 있습니다. Android Studio 기본 Debug 앱 또는 다른 키로 서명된 앱은 충돌할 수 있습니다.

서명/패키지 충돌이 뜨면 기존 앱을 삭제하지 말고 [서명 대응 안내](APK-SIGNING-RECOVERY.md)를 확인합니다. 앱 삭제·데이터 삭제는 암호화 자료와 키를 잃게 할 수 있습니다. XLSX는 전체 복원 백업이 아닙니다. 다운그레이드나 보안 정책 우회로 해결하지 않습니다.
