기준일: 2026-10-19. 구현 여부와 검증 여부를 구분합니다. 완성률은 별도 합의된 요구사항 분모가 없어 수치로 표시하지 않습니다.

## 구현 및 반영 완료

- 어르신·승하차장소 CRUD, ID 기반 연결, 장소 일괄 등록.
- 이름 기준 가나다순 목록 및 연결 대상 정렬, 주소 검색·현재 좌표 등록.
- 등원/하원 시작 버튼 분리, 대상 선택, 단일 장소 자동 선택.
- GPS 도착 추정, 진행 상태, 감지 중단·재개, 종료 및 중복 방지.
- 날짜별 완료 운행 내역, 이름과 도착 시간 중심의 상세 화면.
- 원하는 날짜의 운행을 선택하여 XLSX 출력: 날짜 / 어르신 이름 / 등원 시간 / 하원 시간.
- 블루 테마, 중립적 어르신 심볼, 하단 플로팅 메뉴, 아이콘 편집·삭제 버튼.
- 어르신 목록 편집·삭제 버튼 가로 배치.
- 화면 회전 설정 변경 처리 및 기기 상태에 따른 앱 자동 진입 정책.
- Android Keystore AES-256-GCM 내부 저장, 저장 검증, 기존 데이터 마이그레이션.
